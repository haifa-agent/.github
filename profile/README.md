# Haifa Agent

**简体中文** · [English](README.en.md)

Haifa Agent 为 Java 团队提供构建 AI 助手的基础能力，也把这些能力做成可以直接了解的应用：从写代码、资料研究，到持续推进多步任务。

## 可以用 Haifa Agent 做什么

### Coding Agent

在代码仓库里理解问题、修改文件并运行构建和测试。任务可以跨多轮对话继续推进；开发者可以设定工作范围，并在关键操作前确认。

[查看 Haifa Agent →](https://github.com/haifa-agent/haifa-agent)

### DeerFlow AI 工作台

一个可在本地运行的 AI 工作台，用对话完成资料检索、文件处理和多步骤任务。它复用了字节跳动开源项目 [DeerFlow](https://github.com/bytedance/deer-flow) 的界面与交互方式；你可以查看任务进展、确认需要审批的操作，并获取整理好的结果。

[查看 Haifa Super Harness →](https://github.com/haifa-agent/haifa-agent-super-harness)

### Personal Assistant

在自己的电脑上持续对话、搜索信息和处理日常任务。它可以记住获准保留的信息，也能通过扩展能力处理更具体的工作。

### 从对话走向持续任务

- **Mission** — 把一个长期目标拆成多个步骤，持续记录进展，方便之后接着推进。
- **Deep Research** — 搜集和整理多方资料，形成带来源线索的研究报告，便于核对结论。
